# Ten Themes

Static site served at https://ten-themes.vercel.app/ — three self-contained HTML pages (inline CSS/JS, data baked in).

- `index.html` — Trading Desk (`/`)
- `backtest/index.html` — Pick Backtest (`/backtest`)
- `map/index.html` — Macro & Market Map (`/map`)

No build step; deploy the folder as-is (e.g. `vercel --prod`).

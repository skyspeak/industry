# Ten Themes — published site

Rendered pages for https://ten-themes.vercel.app/. **Do not edit by hand** — these files are generated by the weekly pipeline in [skyspeak/finance](https://github.com/skyspeak/finance) (`job.py` → `publish.py`), which commits `public/` here. Vercel deploys every push to `main`.

| Path | File |
|---|---|
| `/` (`/desk`) | `public/index.html` — trading desk |
| `/map` (`/map-room`) | `public/map.html` — macro & market map |
| `/backtest` (`/lab`) | `public/backtest.html` — pick backtest |
| `/email` | `public/email.html` — weekly digest |

`vercel.json` serves `public/` with clean URLs, the rewrites above, and security/cache headers.
